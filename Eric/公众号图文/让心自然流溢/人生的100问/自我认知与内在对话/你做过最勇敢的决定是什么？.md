# 📚 ==核心回答框架：你做过最勇敢的决定是什么？==

## I. **重新定义**“**勇敢**” 

**核心认知**：真正的勇敢不是外部的壮举，而是**克服内在恐惧**、**挑战现状**、或**坚持个人信仰**的决定。

**目的**：将你的故事从“做了什么”转向“**为什么做**”以及“**克服了什么**”。

## II. **选择你的故事角度** 

选择一个能体现你**最高价值观**的角度：

| 角度           | 核心主题             | 你克服的内在恐惧                | 提炼关键词       |
| ------------ | ---------------- | ----------------------- | ----------- |
| 1. 🚀 职业/转型  | 放弃既得的稳定与舒适。      | **对失败和不确定性的恐惧**。        | 转型、跳出舒适区、远见 |
| 2. 🌱 价值观/原则 | 在压力下坚持道德底线或真实自我。 | **被孤立、冲突或被视为麻烦制造者的风险**。 | 正直、说“不”、原则  |
| 3. 🧩 情感/人际  | 面对痛苦的真相或承认自身脆弱。  | **失去、被评判或承认弱点的痛苦**。     | 坦诚、脆弱、放手    |

## III. **四步结构化叙事** 

使用以下四个步骤，确保你的回答**逻辑严密**、**富有深度**：

| 步骤  | 名称    | 核心功能与内容                                    | 关键思考点           |
| --- | ----- | ------------------------------------------ | --------------- |
| 1.  | 提出观点  | 直接点题，快速说明你的决定是什么。                          | 我最勇敢的决定是...     |
| 2.  | 情境描述  | 描绘当时的背景和风险。重点强调：当时安逸/主流的选择是什么？你面临的最大压力是什么？ | 当时我放弃了什么？       |
| 3.  | 行动过程  | 描述你为执行该决定所做的具体、有计划的努力。                     | 我做了哪些有意识的准备或付出？ |
| 4.  | 结果与反思 | 升华主题。这个决定如何改变了你？它教会了你关于韧性或价值观的什么？          | 这次经历如何让我成长？     |
## 🔑 **最后的关键建议**

- **真诚性至上**：选择你能够真实流露情感、经过深思熟虑的决定。
- **转化力**：确保结论是将这次勇敢的行为，与你现在的积极驱动力或个人成熟度挂钩。
