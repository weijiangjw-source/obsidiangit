# 引力法则

## 核心论断

> 不必大声疾呼。当你站得足够稳，真正需要跃迁的人，自然会向你泅渡。

你不是推手，你就是灯塔。

## 与相关概念的关系

### [[concepts/战略定力型不在乎]]

引力法则与"不动而吸引"的逻辑同构：
- 战略定力型不在乎：通过稳定存在吸引而非推动
- 引力法则：通过站得稳吸引而非呼喊

### [[concepts/三层不在乎操作]]

引力法则可视为三层不在乎的哲学基础：
- 如实描述 → 提供参考系
- 稳定存在 → 成为灯塔
- 拒绝背书 → 不破坏对方稳态

### [[concepts/拯救欲陷阱]]

引力法则是拯救欲陷阱的反面解决方案：
- 拯救欲：试图推动他人改变 → 触发物理排异
- 引力法则：稳定存在吸引他人 → 自然泅渡

## 操作规范

| 行为 | 说明 |
|------|------|
| 如实描述 | 呈现客观现实，不带诱导和包装 |
| 稳定存在 | 在新高度活得自洽、丰盈，让自己可被看见 |
| 拒绝背书 | 不主动拆解对方世界，也不为虚假稳态提供支撑 |
