在 AI 短剧与动态漫创作领域，目前的行业格局分为**“云端开箱即用的 SaaS 平台”**和**“本地开源全自动工作流框架”**两大类型。

如果你希望结合 **Claude Code** 或 Terminal 自动化脚本来进行管线化（Pipeline）创作，**“开源框架 + 代码驱动渲染”** 是实现真正全自动化的最佳方案。

以下是为你整理的工具矩阵与自动化方案：

## 一、 开源/本地部署的“全自动视频生成”框架

如果你想在 Mac 本地搭建环境、用 API 和命令行一键出片，以下开源项目是目前最好的基底：

### 1. MoneyPrinterTurbo (GitHub 热门开源)

- **定位：** 极简的全自动短视频/短剧流水线工具。
    
- **工作流：** 只需要提供主题或脚本，自动调用 LLM 写分镜 ➔ 调用文生图/视频 API 匹配画面 ➔ 调用 Edge-TTS/Fish-Audio 配音 ➔ 自动对齐字幕与 BGM ➔ 导出 HD 视频。
    
- **Mac 部署与 CLI 支持：** 支持 macOS 本地部署（Python/uv 或 Docker）。提供 **WebUI、API 与 CLI 命令行模式**，非常适合直接用 Claude Code 调用其 CLI 或 API 进行批处理。
    

### 2. ComfyUI + ComfyUI-StoryDiffusion (本地漫剧绘制)

- **定位：** 本地部署的 AI 漫画/动态漫分镜生成引擎。
    
- **特点：** 漫剧的核心痛点是**“角色一致性”**（角色的脸和衣服不能帧帧变）。StoryDiffusion 插件能保证同一个角色在不同分镜画面中保持高度一致。
    
- **Mac 性能：** 支持 Mac Apple Silicon (MPS 加速)。ComfyUI 本身提供 WebSocket/REST API，Claude Code 可以直接生成 API 请求 JSON 来批量生成剧情分镜。
    

### 3. SkyReels (昆仑万维开源短剧生成系统)

- **定位：** 专门面向 AI 短剧的开源模型与生成框架 (SkyReels-V1/A1)。
    
- **特点：** 相比普通视频生成工具，它专门针对短剧场景优化了**角色表情（33种）、肢体动作（400种）和多角度运镜控制**。
    

## 二、 云端“一站式”AI 短剧/漫剧 SaaS 平台

如果你不想折腾本地环境，只想提供剧本或小说，让平台一键帮你完成图文到短剧的渲染：

|平台名称|核心优势|是否免费 / 成本|适合场景|
|---|---|---|---|
|**即梦 AI (Dreamina)**|画面一致性高，画质极强，支持镜头运动控制|每日登录赠送积分，高级功能需订阅会员|高精致度漫剧分镜与动态短剧|
|**可灵 AI (Kling)**|动作流畅度与动态视频生成天花板|提供免费体验额度，按生成点卡付费|逼真真人类 short-video / 动态漫|
|**造影 AI / 漫剧鹅**|针对小说推文、漫剧专门设计的自动拆图、配音、卡点流水线|免费试用，后续按月/按集付费|小说转动态漫、推文短视频批量生产|
|**CapCut / 剪映“一键文生短剧”**|内置文本到视频自动合成，字幕音效全包|基础免费，部分音色与高级功能需 VIP|极速出片、小红书/抖音/B站短视频|

## 三、 高阶玩家方案：利用 Claude Code 搭建“全自动化短剧管线”

在 Mac 上，通过结合 **Claude Code + Python/Node.js + Remotion/FFmpeg**，你可以构建一个无缝的全自动短剧生产线。

```
[文本/小说] ➔ (Claude Code 分析) ➔ [JSON 分镜表] ➔ (API 批量生成图音) ➔ (本地脚本渲染) ➔ [最终 MP4]
```

### 最佳自动化技术栈搭配：

1. **分镜与剧本解析 (Claude Code)：**
    
    - 在 Terminal 中运行 Claude Code，让它读取本地小说 `.md` 文件，输出标准化分镜 JSON（包含 `scene_id`, `prompt`, `dialogue`, `voice_id`, `camera_motion`）。
        
2. **资产生成 (Python API 脚本)：**
    
    - **音频：** 脚本自动调用 `edge-tts`（免费且高音质）生成对话语音，并用 `whisper` 或 `edge-tts` 导出带时间轴的 `.srt` 字幕。
        
    - **画面：** 脚本调用本地 ComfyUI API 或云端 API（如 Fal.ai / Flux / SD3），批量输出符合一致性 Prompt 的图片或短视频。
        
3. **合成与渲染 (Remotion 或 MoviePy)：**
    
    - 使用 **Remotion**（基于 React/Node.js 的代码驱动视频渲染工具）或 Python **MoviePy**。
        
    - Claude Code 会自动读取 JSON，直接生成或执行 Remotion 渲染命令（如 `npx remotion render ShortDrama.tsx output.mp4`），自动打上推拉运镜（Pan-Zoom）、字幕字幕淡入、BGM 自动压音（Ducking）。
