# 恐惧被拒

## 定义

**恐惧被拒**是指个体难以拒绝他人请求的心理障碍，其根源在于害怕让对方失望或破坏关系。它是 [[concepts/心力防火墙]] 第三层需要克服的核心心理机制，与 [[concepts/讨好]] 高度相关。

## 心理机制

恐惧被拒的内在循环：
1. 他人提出请求
2. 拒绝 → 害怕对方失望/生气
3. 妥协答应 → 积累怨气
4. 怨气外溢为被动攻击或内耗

## 与 [[concepts/讨好]] 的关系

恐惧被拒是讨好行为的深层动机之一：
- 讨好者：通过顺从来维持关系
- 恐惧被拒：害怕失去关系而不敢拒绝

两者都导致能量泄漏和内在冲突。

## 认知重构策略

| 旧认知 | 新认知 |
| ------ | ------ |
| "拒绝会让别人失望" | "拒绝是对自己优先级的尊重" |
| "我必须让所有人都满意" | "我无法同时满足所有人" |
| "拒绝会破坏关系" | "健康的关系能容纳合理的拒绝" |
| "不好意思拒绝" | "我必须保护我的高价值时间" |

## 实操方法

### 拒绝脚本
预先准备好礼貌但坚定的拒绝语，减少临场决策压力。

### 自我提醒
> "你的'不'字，是你最有力的自我保护。"

## 潜在张力

- 恐惧被拒的消除不等于变得冷漠或自私
- 需要在自我保护和关系维护之间找到平衡点
- 与[[concepts/共同体感觉]]存在张力，需区分健康边界与情感疏离
