## 一、 两种方案的分工与协同流程

### 1. 幕后生产线（ComfyUI + Claude Code 脚本）

> **定位：** 负责“从 0 到 80%”的素材生成与初始工程搭建。

- **特点：** 高度自动化、后台无界面运行、吃算力。
    
- **分工职责：**
    
    1. **剧本结构化：** Claude Code 读取文本/小说，自动分析并输出包含镜头描述、角色表情、台词与情感的标准化 JSON 字典。
        
    2. **角色一致性绘图：** Python 脚本自动调用本地 ComfyUI API，利用 **StoryDiffusion** 节点生成主角“不变脸”的高清漫剧分镜图。
        
    3. **语音与配音合成：** 调用 `edge-tts` 或 `Fish Audio` 批量生成台词音频。
        
    4. **粗剪工程打包：** 自动将图片与音频按照时间轴打标，打包导出为 `.fcpxml` 或 `.otio` 工程文件。
        

### 2. 台前精修区（DaVinci Resolve 免费版 + MCP Bridge）

> **定位：** 负责“从 80% 到 100%”的灵魂质感调优与成品输出。

- **特点：** 自然语言交互、可视化调节、直观精准。
    
- **分工职责：**
    
    1. **工程一键导入：** 在达芬奇中打开上游生成的粗剪工程。
        
    2. **对话式运镜与卡点：** 告诉 Claude：_“把第 3 个镜头放大 120% 并做缓慢推镜头”_、_“把第 8 秒的转场换成卡点标记”_。
        
    3. **免费替代 Studio AI 功能：** 借助 MCP Bridge 内置的开源 AI 替代模型，直接用自然语言执行：
        
        - **自动生成字幕：** 自动调用 `faster-whisper` 生成精确到词的字幕。
            
        - **人声背景分离：** 自动调用 Meta 的 `Demucs v4` 消除杂音或提取人声。
            
        - **智能抠图换背景：** 自动调用 `rembg` 完成图像/视频抠图。
            
    4. **自动渲染导出：** 语音指令触发渲染队列，直接导出 4K/1080P 成品 MP4。

## 三、 Mac 端快速部署关键步骤

### Step 1: 部署本地 ComfyUI（上游）

1. 下载并安装 **Stability Matrix**（支持 Mac M 芯片原生加速）。
    
2. 在软件内一键安装 **ComfyUI**，启动后下载动漫类模型（如 `Animagine XL` 或 `Flux.1`）。
    
3. 安装 `ComfyUI_StoryDiffusion` 节点，用于角色一致性生成。
    

### Step 2: 安装达芬奇免费版与 MCP Bridge（下游）

1. 下载安装 **DaVinci Resolve (免费版)**。
    
2. 在终端获取 MCP 桥接项目：
    
    ```bash
    git clone https://github.com/hiteshK03/davinci-resolve-mcp.git
    cd davinci-resolve-mcp
    pip install -r requirements.txt
    ```
    
3. 将项目中的内部桥接脚本 `CursorBridge.py` 复制到 macOS 的达芬奇脚本目录：
    
    ```path
    ~/Library/Application Support/Blackmagic Design/DaVinci Resolve/Fusion/Scripts/Utility/
    ```
    
4. 打开达芬奇免费版，点击顶部菜单栏：`**Workspace (工作区) ➔ Scripts (脚本) ➔ CursorBridge**`，启动本地桥接。
    
5. 在你的 MCP 配置文件（如 `claude_desktop_config.json` 或 `.cursor/mcp.json`）中接入该服务即可。
