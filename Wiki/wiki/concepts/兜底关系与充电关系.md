# 兜底关系 vs 充电关系

## 定义

健康关系的两种基本功能分类：**兜底型关系**提供风险担保（生存保障），**充电型关系**提供日常能量补给（心理滋养）。二者构成社交关系的二元法则。

## 兜底关系（安全基地型）

| 维度 | 描述 |
|------|------|
| 本质 | 生存与托底 |
| 功能 | 提供超越一般友谊的兜底支持 |
| 触发场景 | 关键时刻（风险、损失、重创） |
| 交互特征 | 无需频繁见面或共同话题；需要生死之交的信赖 |
| 建立门槛 | 极高（共同患难或岁月沉淀） |
| 底层逻辑 | **非理性原则**：即使利益不划算也付出 |

## 充电关系（心理闪充型）

| 维度 | 描述 |
|------|------|
| 本质 | 共鸣与滋养 |
| 功能 | 相互输送能量，修复情绪磨损 |
| 触发场景 | 日常交流（兴趣同频） |
| 交互特征 | 低阻尼对话；主体性完整，无需伪装 |
| 建立门槛 | 较低（兴趣筛选可主动构建） |
| 底层逻辑 | **认知流畅度**：大脑省电模式，产生心流 |

## 核心诊断：错位匹配

社交疲惫的根源在于**错位匹配**：
- 在功能性关系里求情感共鸣
- 在情绪搭子身上求风险担保

这种错配导致关系承担了超出其功能属性的期望，最终引发耗竭。
