聆听是一场关于真诚的对话，不管是聆听自己，还是聆听与你对话的人。

# 一、警惕无效沟通：建议背后的动机与聆听的本质

我们很多人在对话交流当中，都会时不时的去给对方提建议，这样做的目的无非就两个：**一是不愿意听你那乱七八糟的经历，想敷衍你；二是想展示自己智慧的优越性**。对方的潜在逻辑其实是如果你不是那么愚蠢，怎么会面对这么愚蠢的问题。

**所以说，聆听其实就是关注的表现**。当对方获得聆听者的关注的时候，就会更愿意敞开心扉，清晰的告诉你很多事情，面对的问题以及解决方式。有时候你也会从其中获得一些启发，帮助解决自己已经遇到的或者尚未发生未来可能遇到的问题。



# 二、记忆的重构与边界：用当下改变过去的意义

**聆听的目的就是能真实的听到对方过去真实的经历**。但是，回忆过去也是有选择性的，也不可能完全清晰的回忆起所有同等重要的事情，毕竟你的知识和感知是有限的，无法全面的回忆起一切，也始终没法保持客观，同时，在大多数时候也会受到利益的驱使。既然如此，我们如何描述我们的过去呢？

不同事件之间该如何设定边界让其更为准确呢？ **如果对方无法精准的描述过去，并且赋予它正向意义，那他就不可能在现在获得救赎**。很多人会认为过去是不可能改变的，因为是已经发生的事情，怎么能回到过去去重新设定当时的剧情，这当然不可能。**我这里所说的改变是用现在的理解方式去重新给过去那段经历赋予合理的解释，让其意义发生改变，以当下的视角去重新界定事情的边界，用新的理解方式再去看待过去发生的事情**。这就是用当下改变过去。

我们无法仅仅凭借记忆就去获取过去的客观真相，客观的观察者和准确完整的故事几乎是不存在的，存在的只是主观和片面的视角，但我们可以获得更好的视角去看待。 **记忆也只是一种工具，让我们可以用过去指导未来**。如果你遇到了不好的事情且搞清楚了其中真正的原因，那么未来就可以避免这种事情再次发生。

**所以，我们记忆的目的并不是记住过去，而是避免重蹈覆辙，我们必须从记忆中汲取教训，获得新知**。

# 三、思考的本质：内在的冲突、谈判与达成共识

有时候，你必须改变理解事物的一切方式，然后才能理解某一具体的事情。 **如果要理解具体的事情，你必须使用正确的词语，去组建正确的句子和段落**。

如果要清晰的描述过去，就需要精准的表达，而这又与思考是密不可分的。倘若不思考，表达就会混乱不堪，甚至会让你误入歧途。

思考其实就是模拟世界且规划自己的行动，然后才能搞清楚哪些蠢事是不需要做的，进而避免恶果。这样的思考才有意义。 很多人认为自己会思考，但事实并非如此。**大多数时候我们是在进行自我批判，真正的思考如同真正的聆听一样少见**。

思考其实就是聆听自己，而这并不容易。**要思考，你至少要同时分饰两个虚拟角色，而且还允许各种矛盾和冲突。思考是两个以上世界观之间的对话**。每一个虚拟角色都有各自不同的视角，都会对过去、现在和未来有着自己的理解，也有各自的行为逻辑。思考就是这几个虚拟角色相互沟通并最终达成共识的过程。你不能提前预设某一方是错误的，这不是思考，这是“**事后诸葛亮**”。

**真正的思考是复杂且要求很高的事情，你需要既能清晰的表达又能审慎、明智的聆听。真正的思考会涉及冲突和对抗，你必须要能够容忍和接纳。冲突包括谈判和妥协，所以你也要懂得如何讨价还价并给自己做心理建设**。你内在的虚拟角色并不会轻易妥协，它们也会为了自我生存而跟你搏斗。所以，你最好接纳他们的存在，并认真聆听它们，去获得自己内心最真实的需求。

否则，他就会不停的去折磨你，直到你屈服，选择去做违背你真实需求的相反事情。 思考自始至终是一件情感上痛苦，身体上辛苦的事情。要进行这一切，你必须变得头脑清晰且敏锐。**那如果确实不善于思考，该如何？很简单，说话就行了，不过需要有人聆听**。聆听者就是我们的合作者或者是对手。

**聆听者可以在不说话的情况下测试你的表达和想法，是一个很好的反馈者**。如果你的话让大多数人感到惊诧，你或许应该重新考虑自己表达的内容。话虽如此，但我很清楚有时引发争议才是正确的，过去很多拒绝聆听的人正是栽在了闭目塞听上。

所以，如果你执意坚持自己的方式，坚持自己的看法，最好有自己经过充分思考后的理由，否则你的结果可能会很糟。 也就是说，**除非你理由很充分，否则你最好追随大家的选择。当你走在别人已经走过的道路上时，别人跳过的坑，撞过的壁会让你少走很多弯路**。这就是前人智慧的重要性所在，如果不能很好的利用，必定会吃大亏。

# 四、真正的聆听：抛弃评判的勇气与转化的力量



很多时候我们必须学会如何与别人相处，这样才能知道对方的坦诚反馈，这比要直接告诉对方事情的对错要更有价值。**双方彼此说实话的过程，就是在聆听彼此**。

聆听是一个非常艰难的事情。很多人会说我善于聆听，其实这并不是真正的聆听。很多人在聆听的时候，其实都是带着自我评判的视角去评判对方的，你没有带入到对方的情境中，你也没有真正理解对方在说什么，你也会很武断的简化和扭曲对方的观点，所以会把聆听变成是一个评判过程，**这种居高临下的沟通方式很容易产生冲突和矛盾，压制对方的真实想法，让沟通陷入尴尬和停止**。

20世纪最伟大的心理咨询师之一卡尔·罗杰斯写道：“**我们大多数人无法坚持聆听，总是忍不住要去评价，因为聆听太危险了。聆听的首要要求是勇气，而我们并不总具备勇气**。”

他还评论道：“你们有的人以为自己善于聆听，却从未改变过别人。这很有可能是因为你们的聆听并不是我所描述的那种聆听。” 真正的聆听是有很大的好处的。

比如说：

**首先，你能真正理解别人在说什么，这是极为重要的一点**。如果你真的渴望理解一个人，愿意走进他的内心世界去看他眼中的生活，那么你自己就很有可能被改变。你会从他的角度去看世界，你的态度和性格都会受到影响。这是极其有价值的一件事。而对于大部分人来说，被改变是最可怕的事情之一。

**其次，它能帮助你重新整合过去的叙事方式。会告诉你发生了什么，原因是什么、未来要避免同样的结果你需要做什么**。记忆的目的不是要准确记录过去，而是要帮助你更好地面对未来。

**最后，避免陷入片面的误解。人一旦遭到反对的时候，都会忍不住过度简化和扭曲对方观点**。这么做不仅伤害了对方，也损害了自己的立场。相反，如果你能先总结对方的观点并让对方认同你的总结，当你站在对方的角度去思考时，你要么会发现其中有价值的部分从而有所收获，要么会找到更好的反驳方式。这样你就不再需要曲解对方的观点，而且也可减少误解和自我怀疑。

很多时候，每一个人在表达自己的观点时都不可能尽善尽美，表达能力也不尽相同，难免有钻牛角尖和自相矛盾的可能。

所以，表达和思考在更多时候在于你忘掉了什么，而不是还记得什么。尤其是在讨论一些能引起极大情绪化的主题时，比如死亡、重大疾病或者重大创伤等等，我们会选择性的回避一些东西。**但要形成清晰的想法，我们需要先完整的描述整个体验细节，包括那些看上去多于的部分**。只有这样，我们才能抓住核心，找到因果关系。

# 五、平等对话的价值：拓展未知与滋养自我

**积极的聆听是不带有任何评判的，这同时也能体现出聆听者的同理心，能接纳对方叙事中的各种情绪**。也可以激发对方真实的吐露。丰富的细节叙述这也会让对话显得非常有趣。事实上，你也可以以此来判断自己的聆听态度：如果你感觉对话无聊，那说明你可能没有在认真聆听。

**不是所有的对话都是思考，也并不是所有的倾听都能促使转变**。每个人听和说的动机并不相同，有些动机会带来沟通中激烈的情绪对抗，各自为政，自话自说。比如，很多人的对话只是在彰显自己的地位，伸张自我权力，强调我的正确性。很显然，在一种权力压制下的对话无法有效对话，也无法真正聆听。这样的对话明显已经偏离里真正的主题。

**这种对话的目的就是强调让对方支持涵盖一切、单一和过度简化的世界观，而不是鼓励双方思考**。

**所以，我们的对话必须站在同一层面上，没有高低，没有评判，没有贬损**。让真正的聆听参与到对话里，当一个人表达时，所有人都会聆听，表达的人可以有机会讨论任何不开心甚至悲剧的事情，而倾听者也都会报以同理心去回应对方。**这种对话的最大意义在于：允余表达者一边讲述，一边在脑海里梳理，不开心的事情。大家都可以通过对话来整理思绪，这是一个不争的事实**。

人如果找不到倾诉对象，心理的垃圾就会越积越多，最终会危机我们的心理健康。**人们心理的健康在很大程度上归功于通过他人反馈来维持复杂自我的正常运转的能力**。

**我们将自己理智无法解决的问题外包给了别人，因此我们要更好的学会与别人相处**。如果一个人能够被别人接纳，那么他就有条件从自己所处的社会环境里获得反馈。人们的关注、认同、嘲讽甚至轻抬眉毛都可以帮他确认自己的言行是否恰当。

**真诚对话中的同情反馈让表达的人感到自己是有价值的，自己的故事是重要、值得关注和可以理解的**。比如：男女双方在讨论某些具体问题时总是彼此误解，女方总是指责对方急于解决问题，注意力不在自己身上，不能很好的理解自己，不去聆听自己唠叨。

**如果此时我们把对话方式转变为共同探讨的方式，那么我们都会在彼此的沟通中获益**。这种对话需要听和说的人都要为彼此着想，尊重对方的个人经验，让大家都有机会表达和整理自己的想法。大家必须优先假设自己需要通过学习去解决问题，而不是一味的坚持自己的立场。

很明显，这样的对话更有利于大家共同探索未知，而不是局限在已知层面的僵持固守。你也必须相信对方分享的结论在一定程度上也可以帮助你避免犯同样的错误。**你也必须沉思，而不是强调对错，试图取胜。***

如果你不这样做，无疑是在重复自己已有的知识，自以为是的寻求认同。但如果你这样做的话，那么你就会发现别人内心深处呈现出来的崭新思想，这样你也就在无形中扩大了自己的未知圈，吸收了别人的经验部分。 **记住：当你在聆听他人的是时候，其实也是在聆听自己，发现自己，滋养自己，扩展自己。**

当你能够一只脚踏入清晰，另一只脚踏入模糊，你就能找到自己正确的位置。换句话说就是，你即不能在已知里陷入太久，还要能不断的去触摸到已知边界之外的区域，把自己的已知边界扩大，采用的最佳方式就是真正的去聆听别人，同时也要聆听自己。**当大家都能摘下彼此的面具，就能看见彼此的探求之心。**

**聆听自己，聆听与你对话的人。这并不局限于你已经拥有的知识，去不断寻求新知，这才是最大的智慧。**
