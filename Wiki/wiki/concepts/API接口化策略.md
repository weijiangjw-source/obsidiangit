# API 接口化策略

## 定义

将行为与自我剥离，按需调用社交接口的策略。不把行为上升到自我层面，而是视作可调用的工具。

## 核心操作

- 需要开会时 → 调用外向接口，表演专业职场人
- 会议结束 → 立刻切断电源

## 理论依据

这不被定义为虚伪，而被定义为 **工具理性**。行为是策略性调用，而非真实自我的表达或缺陷。

## 与其他概念的关联

- [[性格作为被环境冻结的生存策略]] — 这是破局策略之一
- [[印象管理]] — 与 Goffman 的拟剧论有共鸣，但本文更强调工具性而非表演性

## 实践边界

该策略适用于职场等需要角色扮演的情境，但不意味着否定真实性自我的价值。它是「支付做自己租金」策略的配套手段。
