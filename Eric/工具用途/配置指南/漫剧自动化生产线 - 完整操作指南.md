## 阶段一：ComfyUI 环境部署

### 1.1 目录结构规范（重要！）

**路径命名必须全小写，避免后续迁移问题：**

```bash
# ✅ 推荐
/Users/用户名/projects/ComfyUI

# ❌ 避免
/Users/用户名/Projects/ComfyUI  # 大写可能导致 Linux 迁移问题
```

### 1.2 部署步骤

```bash
# 1. 克隆 ComfyUI
cd /Users/eric/projects
git clone https://github.com/comfyanonymous/ComfyUI.git
cd ComfyUI

# 2. 创建虚拟环境（Python 3.11，不要用最新版）
python3.11 -m venv venv
source venv/bin/activate

# 3. 安装依赖
pip install --upgrade pip
pip install torch torchvision torchaudio
pip install -r requirements.txt

# 4. 安装 IP-Adapter Plus 插件
cd custom_nodes
git clone https://github.com/cubiq/ComfyUI_IPAdapter_plus.git
cd ..
```

### 1.3 关键目录结构

```
ComfyUI/
├── models/
│   ├── checkpoints/      # 基础模型（SD 1.5 / SDXL）
│   ├── ipadapter/        # IP-Adapter 模型文件
│   └── clip_vision/      # CLIP Vision 编码器
├── custom_nodes/
│   └── ComfyUI_IPAdapter_plus/
├── input/                # 参考图存放位置
├── output/               # 生成图片输出
└── user/default/workflows/  # 工作流保存位置
```

```bash

# 常用命令

pm2 restart comfyui   # 重启
```

### ⚠️ 常见坑

| 问题 | 原因 | 解决方案 |
| :--- | :--- | :--- |
| `--use-mps` 报错 | 新版自动检测，不需要手动指定 | 直接 `python main.py` |

## 阶段三：工作流搭建与调试

### 3.1 节点连接规范（标准工作流）

```
Load Checkpoint (MODEL) → IPAdapter (model)
Load Checkpoint (CLIP)  → CLIP Text Encode (Prompt) (clip)
Load Checkpoint (CLIP)  → CLIP Text Encode (Negative) (clip)
Load Checkpoint (VAE)   → VAEDecode (vae)
Load CLIP Vision        → IPAdapter (clip_vision)
Load Image              → IPAdapter (image)
IPAdapter (MODEL)       → KSampler (model)
CLIP Text Encode (Prompt) → KSampler (positive)
CLIP Text Encode (Negative) → KSampler (negative)
Empty Latent Image      → KSampler (latent_image)
KSampler (LATENT)       → VAEDecode (samples)   # 注意：端口名是 samples，不是 latent！
VAEDecode (IMAGE)       → Save Image (images)
```

### 3.2 IP-Adapter 节点选择（关键！）

**这里有三种节点，区别很大：**

| 节点名称 | 何时使用 | 特点 |
| :--- | :--- | :--- |
| `IPAdapter` | 标准场景 | 需要外部连接 `clip_vision` 和 `image` |
| `IPAdapter Unified Loader` | 快速测试 | 内部集成，通过下拉菜单选择 |
| `IPAdapter Advanced` | 精细控制 | 最灵活，参数最多 |
| `IPAdapter Model Loader` | 配合 Advanced | 单独加载模型文件，输出给 Advanced |

**⚠️ 最容易混淆的地方：**
- 标准 `IPAdapter` 节点中，`ipadapter` 如果是**连接点（端口）**，需要配合 `IPAdapter Model Loader` 使用。
- 如果 `ipadapter` 是**下拉菜单**，则无需外部连接。
- `IPAdapter Advanced` + `IPAdapter Model Loader` 是最可靠的组合。

### 3.3 关键参数设置（IPAdapter Advanced）

| 参数 | 推荐值 | 说明 |
| :--- | :--- | :--- |
| `weight` | 0.45~0.7 | 锁脸强度，太高会压制提示词 |
| `start_at` | 0.2 | 让前 20% 步数自由构图 |
| `end_at` | 1.0 | 全程保持 |
| `weight_type` | `linear` | 线性变化 |
| `combine_embeds` | `concat` | 特征拼接方式 |
| `embeds_scaling` | `V only` | 仅缩放 V 分量 |

### 3.4 VAE Decode 节点

**注意：** 标准 `VAEDecode` 节点的输入端口是 **`samples`**，不是 `latent`。搜索时输入 `VAEDecode`（无空格）添加。

### 3.5 测试单张生成

1. 在 `Load Image` 中上传参考图（1:1 比例，正脸）
2. 填写测试提示词（英文优先）
3. 点击 `Run` 或顶部 `Queue Prompt`
4. 成功标志：生成的图片人脸与参考图相似

| `CLIP-ViT-bigG-14-laion2B-39B-b160k.safetensors` | h94/IP-Adapter | `models/clip_vision/` | ~2.5GB |

**下载链接（国内镜像）：**
```
https://hf-mirror.com/stabilityai/stable-diffusion-xl-base-1.0/resolve/main/sd_xl_base_1.0.safetensors
https://hf-mirror.com/h94/IP-Adapter/resolve/main/sdxl_models/ip-adapter_sdxl.safetensors
https://hf-mirror.com/h94/IP-Adapter/resolve/main/models/image_encoder/CLIP-ViT-bigG-14-laion2B-39B-b160k.safetensors
```

### 4.2 切换到 SDXL 必须做的调整

| 配置项 | SD 1.5 | SDXL |
| :--- | :--- | :--- |
| `Load Checkpoint` | `v1-5-pruned-emaonly` | `sd_xl_base_1.0.safetensors` |
| `IPAdapter Model Loader` | `ip-adapter_sd15` | `ip-adapter_sdxl.safetensors` |
| `Load CLIP Vision` | `CLIP-ViT-H-14...` | `CLIP-ViT-bigG-14...` |
| `Empty Latent Image` | `512x512` | **`1024x1024`**（必须调高！） |

### 4.3 ⚠️ SDXL 常见报错

**报错：** `size mismatch for proj.weight: shape [8192, 1280] vs [8192, 1024]`

**原因：** CLIP Vision 模型与 IP-Adapter 不匹配（用了 SD 1.5 的 CLIP Vision）

**解决方案：** 确保 `Load CLIP Vision` 选择的是 `CLIP-ViT-bigG-14-laion2B-39B-b160k.safetensors`

```
# 1. 初始化项目
$short-drama 初始化一个都市打脸题材的短剧项目，竖屏 9:16

# 2. 写第一集
$short-drama-write 写第 1 集：外卖员在高档餐厅被经理羞辱，亮出集团董事身份

# 3. 拆资产（人物/场景/道具）

# 4. 生成分镜
$short-drama-storyboard 给第 1 集做分镜

# 5. 生成图片提示词
$short-drama-image-prompts 为已接受的分镜生成图片提示词
```

### 5.3 输出文件说明

| 文件 | 位置 | 用途 |
| :--- | :--- | :--- |
| `short-drama.json` | 项目根目录 | 项目配置 |
| `storyboard.md` | `剧集/EP001/` | 人类可读的分镜描述 |
| `scene-image-prompts.jsonl` | `剧集/EP001/assets/` | **AI 图片提示词（脚本读取）** |

### ⚠️ 关键区分：资产描述 vs 分镜描述

- **资产描述**（`image-prompt-specs.jsonl`）：角色设定卡，用于生成定妆照，所有图片都类似
- **分镜描述**（`scene-image-prompts.jsonl`）：每个镜头的具体场景，图片各不相同

**批量生图必须使用 `scene-image-prompts.jsonl`，而不是 `image-prompt-specs.jsonl`！**

3. 找到包含正向提示词的节点，其外层数字 ID 就是 `PROMPT_NODE_ID`。

```python
def load_prompts(file_path):

    # 读取 JSONL，拼接到提示词前面
    prompt_text = item.get('image_prompt') or item.get('prompt')
```

### 6.4 运行脚本

```bash
cd /Users/eric/short-drama-project
```

### 6.5 ⚠️ 常见问题

| 问题 | 原因 | 解决方案 |
| :--- | :--- | :--- |
| 生成的图片都一样 | 用了资产文件而非分镜文件 | 改为 `scene-image-prompts.jsonl` |
| 图片没有人脸 | 提示词全是中文/没有人物描述 | 添加英文 `CHARACTER_PREFIX` |
| 超时 | SDXL 生成慢 | 增加 `get_image` 循环次数（30→120） |
| 脚本报错找不到节点 | 节点 ID 不正确 | 重新确认 `PROMPT_NODE_ID` |

## 阶段七：达芬奇自动化合成

### 7.1 脚本放置位置

达芬奇脚本必须放在指定目录才能通过菜单运行：

```bash
# 脚本目录
~/Library/Application Support/Blackmagic Design/DaVinci Resolve/Fusion/Scripts/Utility/

# 复制脚本
cp /Users/eric/short-drama-project/create_davinci_project.py ~/Library/Application\ Support/Blackmagic\ Design/DaVinci\ Resolve/Fusion/Scripts/Utility/
```

### 7.2 ⚠️ 关键编码问题

达芬奇的脚本环境不支持 `__file__` 变量，所有路径必须使用**绝对路径**：

```python
# ❌ 错误（会报 NameError）
BASE_DIR = os.path.abspath(os.path.dirname(__file__))

# ✅ 正确
BASE_DIR = "/Users/eric/short-drama-project"
FRAMES_DIR = os.path.join(BASE_DIR, "generated_frames")
```

### 7.3 运行方式

| 方式 | 操作 | 适用场景 |
| :--- | :--- | :--- |
| **脚本菜单** | `工作区` → `脚本` → `Utility` → 点击脚本名 | 最稳定，推荐 |
| **控制台** | `工作区` → `控制台` → Python 标签 | 调试测试 |

### 7.4 控制台运行命令

```python
exec(open('/Users/eric/short-drama-project/create_davinci_project.py', encoding='utf-8').read())
```

### 7.5 图片序列问题（重要！）

达芬奇会自动将连续编号的图片合并为视频序列。

**解决方案：** 导入前临时重命名图片，破坏连续性：

```python
# 使用随机名称
new_name = f"still_{idx+1}_{os.urandom(2).hex()}.png"
shutil.copy2(src_path, dst_path)
```

### 7.6 脚本完整配置

```python
PROJECT_NAME = "外卖王的逆袭"
BASE_DIR = "/Users/eric/short-drama-project"
FRAMES_DIR = os.path.join(BASE_DIR, "generated_frames")
```

### 7.7 导出视频

1. 在达芬奇 **编辑（Edit）** 页面预览时间线。
2. 切换到 **交付（Deliver）** 页面。
3. 设置格式为 MP4 H.264，分辨率 1080x1920。
4. 添加到渲染队列 → 开始渲染。
