# 自我同情

## 定义

**自我同情（Self-Compassion）** 是一个心理学概念，指个体在面对自身痛苦、失败或不足时，以友善、理解的态度对待自己，而非严厉批评或自我否定。该概念由心理学家 Kristin Neff 系统提出，是停止内耗的重要心理机制。

## 核心维度

自我同情包含三个核心成分：

1. **自我友善（Self-Kindness）**：对自己温和、理解，而非苛责
2. **人类共通性（Common Humanity）**：认识到不完美是人类的共同体验
3. **正念觉察（Mindfulness）**：以平衡的方式觉察痛苦，既不压抑也不放大

## 在停止内耗中的作用

### 心理机制

根据 [[sources/停止内耗：你必须为自己立下的 3 道心力防火墙]]，自我同情通过以下路径减少内耗：

| 内耗模式 | 自我同情的干预方式 |
| -------- | ------------------ |
| 自我批判 | 以友善态度替代严厉批评 |
| 社会比较 | 承认人类共通的不完美，减少"唯我独差"的认知 |
| 完美主义驱动 | 接纳瑕疵作为行动起点，而非等待完美的障碍 |

### 与反完美主义的关联

自我同情直接对抗完美主义的内耗循环：
- 完美主义者：结果不完美 → 自我惩罚 → 拖延 → 更严重的自我批判
- 自我同情者：接纳不完美 → 肯定努力 → 行动启动 → 正向循环

## 实操方法

### 晨间自我提醒
> "我的价值由我定义，不以他人的标准或成就为转移。"

### 奖励机制重构
不因结果完美而奖励自己，而因真实且勇敢的尝试而肯定自己。

## 与相关概念的辨析

### 与 [[concepts/自爱]] 的关系

自我同情是自爱的心理学操作化版本。自爱更侧重价值立场，自我同情更侧重具体心理技巧。

### 与 [[concepts/虚假自爱与真正自爱]] 的关系

虚假自爱表现为"我需要完美才值得被爱"的条件式自我关怀；自我同情则是无条件的、基于当下的自我接纳。

### 与 [[concepts/有效犒劳]] 的关系

自我同情支持的奖励机制是"过程导向"（奖励努力），而非"结果导向"（奖励完美），与无效犒劳形成对比。

## 局限与注意事项

- 自我同情不等同于自我放纵或降低标准
- 需要与行动力结合，否则可能滑向消极接受
- 在强调集体主义的文化语境中，可能需要调整表达方式以减少认知阻力
