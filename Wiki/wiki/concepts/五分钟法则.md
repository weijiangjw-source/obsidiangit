# 五分钟法则

## 定义

**五分钟法则**（又称五 Minute Rule）是一种行为启动技术：面对任何艰难或拖延的任务，只要求自己先做 **5 分钟**。5 分钟结束后，如果不想继续，可以停止；但大多数情况下，由于 [[concepts/启动惯性]] 的作用，个体会自然继续下去。

## 操作要点

| 要素 | 说明 |
|------|------|
| 时间承诺 | 仅承诺 5 分钟，不保证完成 |
| 启动口号 | "只开始，不保证完成" |
| 工具支持 | 设置闹钟作为边界标记 |
| 退出机制 | 5 分钟后确实不想继续，允许停止 |
| 预期结果 | 大多数时候会自然继续 |

## 心理机制

1. **降低启动阻力**：5 分钟是一个几乎无心理负担的时间承诺，绕过拖延时的自我说服困境。
2. **启动惯性激活**：一旦开始，[[concepts/启动惯性]] 发挥作用，维持比启动更容易。
3. **情绪管理**：避免被任务的"全部体量"吓倒，将注意力聚焦在最低启动成本上。

## 与相关概念的关系

- 与 [[concepts/任务颗粒化]] 配合使用：五分钟法则负责启动，任务颗粒化负责维持和分解。
- 与 [[concepts/学生思维]] 存在潜在张力：学生思维中"任务完成即止"的心态可能与"只做5分钟就停"的原则冲突，需在实践中辨析。
- 与 [[concepts/身份驱动自律]] 互补：五分钟法则是"启动"维度的技术，身份驱动自律是"维持"维度的机制。

## 局限

- 对个人经验型建议，非严格实证论证。
- 对于真正需要深思熟虑而非快速执行的任务，两分钟规则和五分钟法则的适用范围需重新评估。
