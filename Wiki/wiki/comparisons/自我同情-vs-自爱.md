# 自我同情 vs 自爱

## 概述

[[concepts/自我同情]] 和 [[concepts/自爱]] 在停止内耗的框架下高度重合，但侧重点不同。前者是心理学操作化概念，后者是价值立场表述。

## 核心对比

| 维度 | 自我同情 | 自爱 |
| ---- | -------- | ---- |
| **性质** | 心理学概念（Kristin Neff） | 价值立场/生活哲学 |
| **焦点** | 具体心理技巧和方法 | 总体价值取向 |
| **操作化** | 三维度：自我友善、共通人性、正念觉察 | 更抽象，需具体化为行为 |
| **应用场景** | 面对失败、批评、不足时的即时反应 | 长期生活方式和价值判断 |
| **理论基础** | 有实证研究支撑 | 更多来自个人成长/哲学传统 |

## 重叠区域

两者在以下方面高度一致：
1. 停止向外索求认可
2. 建立内在价值标准
3. 接纳自身不完美
4. 将自我价值判断权收回自己手中

## 差异点

| 方面 | 自我同情 | 自爱 |
| ---- | -------- | ---- |
| **面对失败** | 立即启动自我友善对话 | 需要更强的价值信念支撑 |
| **文化适应性** | 更中性，易于跨文化应用 | 在集体主义文化中可能被视为"自私" |
| **与行动的关系** | 更强调当下接纳，可能弱化行动驱动力 | 可与"追求成长"更好整合 |

## 在心力防火墙中的角色

根据 [[sources/停止内耗：你必须为自己立下的 3 道心力防火墙]]，第一道防火墙（价值思维）同时调用两个概念：
- 自我同情提供"停止比较+奖励努力"的心理机制
- 自爱提供"你就是最高价值"的价值立场

## 整合建议

在实际应用中，可将两者视为互补：
- 用自爱确立总体价值方向
- 用自我同情提供具体应对技巧
- 共同服务于"停止内耗、建立边界"的目标
