# 认知铁三角与闭环

**认知铁三角与闭环**是[[concepts/进化型认知|进化型认知]]的核心运行架构。它揭示了真正的认知并非单一的思维能力，而是由导航、动力与减震三个要素紧密耦合而成的闭环进化系统。

## 认知铁三角的结构

```
       思想 (底层逻辑 / 导航系统)
               /        \
              /          \
             /            \
行动 (极致执行 / 动力系统) --- 心态 (系统稳态 / 减震系统)
```

1. **思想（底层逻辑 / 导航系统）：**
   - 解决“是否看透规律”的问题。
   - 区分事物表象与本质，为行动提供准确的路线预判。
2. **行动（极致执行 / 动力系统）：**
   - 解决“能否转化为肌肉记忆”的问题。
   - 包含在信息不完备环境下的“灰度决策”能力，以及应对长期枯燥的执行韧性。
3. **心态（系统稳态 / 减震系统）：**
   - 解决“遭遇失败后是否系统崩溃”的问题。
   - 提供吸收冲击的缓冲力（与[[concepts/内在压舱石|内在压舱石]]相通），并负责将失败转化为系统升级的数据资源。

## 五阶段循环闭环

认知闭环按如下顺序持续循环迭代：

$$\text{逻辑构建 (输入)} \rightarrow \text{极致执行 (加工)} \rightarrow \text{结果反馈 (输出)} \rightarrow \text{心态复盘 (系统升级)} \rightarrow \text{持续迭代 (坚持与调整)}$$

- **脱节病症：**
  - 有思想无行动：陷入“分析瘫痪”与[[concepts/学生思维|学生思维]]。
  - 有行动无心态：一遇挫折即陷入认知的崩溃与[[concepts/防御模式与觉知模式|防御模式]]。
  - 只有当三者打通，认知才具备抗打击能力与复利效应。
