# 七分法则

**七分法则**是目标设定的具体工具，主张用"7分努力 × 7分胜率"替代"100%追求"，避免自我霸凌和习得性无助。

## 核心公式

```
完美目标 = 7分努力 + 7分胜率
```

## 为什么不用100%

| 追求 | 结果 |
|------|------|
| 100%努力 + 100%胜率 | 必然挫败 → 习得性无助 |
| 70%努力 + 70%胜率 | 可控挑战 → 可持续进步 |

## 应用场景

- 工作项目目标设定
- 个人成长计划
- 关系期望管理

## 与相关概念的对比

### 七分法则 vs 防御性悲观
- 防御性悲观：预设最坏结果以降低焦虑
- 七分法则：设定合理预期以保持动力
两者都降低期望，但防御性悲观侧重风险规避，七分法则侧重可持续性。

### 七分法则 vs 控制感错觉
七分法则是打破控制感错觉的工具——承认成功率上限，避免将结果完全归因于个人努力。

## 批判性审视

- 七分法则缺乏实证支撑，属于经验性建议
- "7分"是近似值还是精确标准？适用边界不明确
- 与"大事梭哈"存在张力：大事是否需要突破7分限制？
