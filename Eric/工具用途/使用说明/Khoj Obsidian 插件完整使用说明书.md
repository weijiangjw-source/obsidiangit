# Khoj Obsidian 插件完整使用说明书

> 本文档基于 Khoj 官方文档及实际使用经验整理，涵盖从安装配置到日常使用的完整指南。


## 一、Khoj 是什么

Khoj 是一个开源的、可自托管的个人 AI 助手，核心功能是把你的 Obsidian 笔记、PDF 文档、图片等所有个人知识库，变成一个你可以用自然语言随时对话的“第二大脑”。

**Khoj 的三大核心能力：**

| 功能 | 说明 |
|------|------|
| **Chat（聊天）** | 像对话一样提问，Khoj 基于你的笔记内容生成回答 |
| **Search（语义搜索）** | 用自然语言搜索笔记，理解意图而非匹配关键词 |
| **Similar（相似发现）** | 自动找出与当前笔记内容相似的其他笔记 |

**工作原理：** Khoj 使用嵌入模型将你的笔记转换成“向量指纹”存入数据库。当你提问时，你的问题也被转换成向量，系统找出语义最相似的笔记片段返回给你——这就是为什么它“理解”你的意思，而不仅仅是找关键词。


## 二、前提条件

在使用 Obsidian 插件之前，**必须先确保 Khoj 后端服务正在运行**。

### 2.1 启动 Khoj 服务

打开终端，执行：

```bash
khoj
```

看到以下输出表示服务启动成功：

```
Uvicorn running on http://127.0.0.1:42110 (Press CTRL+C to quit)
```

> **⚠️ 重要**：这个终端窗口必须保持打开，Khoj 服务才能持续运行。关闭终端则服务停止。

### 2.2 验证服务是否正常

在浏览器访问 `http://127.0.0.1:42110`，或在终端执行：

```bash
curl http://127.0.0.1:42110/api/v1/user
```

返回 `{"detail":"Forbidden"}` 表示服务正常运行（匿名模式下这是正常的）。


## 三、安装与连接插件

### 3.1 安装插件

1. 打开 Obsidian → **设置** → **社区插件** → **浏览**
2. 搜索 **Khoj**，点击**安装**
3. 安装完成后，点击**启用**

### 3.2 配置服务器连接

在 Obsidian 的 Khoj 插件设置中：

| 配置项 | 自托管模式的值 |
|--------|---------------|
| **Khoj URL** | `http://127.0.0.1:42110` |
| **Khoj API Key** | **留空**（匿名模式下不需要） |

> **⚠️ 关键提醒**：API Key 必须完全为空，不能有任何字符（包括空格）。如果填入了内容，插件会尝试认证并失败。

### 3.3 首次同步

点击 **`Force Sync`**（强制同步）按钮，Khoj 会开始索引你整个 Obsidian 仓库的所有 Markdown 文件。

- **同步时间**：取决于笔记数量。几十个文件几秒，上千个文件可能需要 10-30 分钟
- **后续同步**：插件默认会自动同步，无需手动操作


## 四、核心功能详解

Khoj 插件提供三种核心交互模式。

### 4.1 Chat（聊天模式）

**用途**：像聊天一样提问，Khoj 基于你的笔记内容生成回答。

**如何打开**：
- 点击左侧 Ribbon（功能区）的 Khoj 聊天图标
- 或按 `Cmd+P` 打开命令面板，输入 `Khoj: Chat`

**使用示例**：
- ❌ `项目复盘`（太简短）
- ✅ `我上次做项目复盘的时候都写了哪些心得体会？`
- ✅ `我去年关于 OKR 目标管理的那些笔记里，主要提到了哪几个关键点？`

**注意事项**：
- Chat 模式需要配置 AI 模型（OpenAI/Claude/本地模型等）才能生成回答
- 如果你没有配置任何聊天模型，Chat 模式可能无法使用

### 4.2 Search（语义搜索模式）

**用途**：用自然语言搜索笔记，理解语义而非匹配关键词。返回的是**相关笔记片段的列表**，不是 AI 生成的答案。

**如何打开**：
- 点击左侧 Ribbon 的 Khoj 搜索图标
- 或按 `Cmd+P`，输入 `Khoj: Search`

**正确用法**：

| 错误示范 ❌ | 正确示范 ✅ |
|------------|------------|
| `项目管理` | `我关于项目风险应对的那些碎片想法` |
| `笔记` | `上个月写的那篇关于如何提高专注力的文章` |
| `复盘` | `我常用的项目复盘框架有哪些？` |

**关键点**：用**完整的、描述性的句子**提问，Khoj 的语义搜索才能发挥最大威力。只搜一个词，效果和传统搜索差不多。

**结果解读**：搜索结果会按相关性排序，显示匹配的笔记片段及其来源文件。

### 4.3 Similar（相似发现模式）

**用途**：基于当前打开的笔记，自动找出库中内容相似的其他笔记。

**如何打开**：
- 按 `Cmd+P`，输入 `Khoj: Find Similar Notes`

**使用场景**：
- 写新笔记时，快速找到之前写过的相关内容
- 发现自己都没意识到的知识连接
- 整理笔记时，发现可以合并的重复内容

**这是 Khoj 最有价值的功能之一**——它能帮你发现“你自己都忘了的关联”。


## 五、高级设置与优化

### 5.1 排除不需要索引的文件夹

在 Obsidian 插件设置中，找到 **`Exclude Folders`**，添加以下类型的文件夹：

- `Templates`（模板文件，无实质内容）
- `Excalidraw`（绘图文件，无法索引文本）
- `Attachments`（图片等附件）
- `Daily Notes` 归档（如果内容重复性高）

排除这些文件夹可以：
- 加快索引速度
- 减少数据库占用
- 提高搜索结果质量（减少噪音）

### 5.2 调整搜索结果数量

在插件设置中找到 **`Results Count`**，调整每次搜索返回的结果数量。默认值通常够用，如果觉得结果太少或太多可以微调。

### 5.3 同步设置

- **`Auto Sync`**：开启后，Khoj 会自动同步你的笔记变更
- **`Sync Notes`**：手动触发同步，只索引 Markdown 文件

### 5.4 过滤搜索范围

在搜索框中可以使用查询过滤器，限制搜索范围。例如只搜索特定文件夹或特定时间范围内的笔记。


## 六、常见问题与故障排除

### 6.1 插件显示“未连接”（状态不变绿）

**现象**：插件界面一直显示灰色“未连接”状态。

**原因**：匿名模式下，插件请求 `/api/v1/user` 接口会返回 403，插件误认为未连接。

**解决**：
- 用 `curl http://127.0.0.1:42110/api/v1/user` 验证服务是否正常运行
- 如果返回 `{"detail":"Forbidden"}`，说明服务正常，**忽略状态指示灯，直接使用即可**
- 确保 API Key 字段**完全为空**

### 6.2 Force Sync 卡住或报错 `Failed to clear existing content index`

**现象**：同步进度条不动，或提示无法清除旧索引。

**解决**：
1. 停止 Khoj 服务（`Ctrl+C`）
2. 删除索引目录：`rm -rf ~/.khoj`
3. 重置数据库：`dropdb postgres && createdb postgres`
4. 重新启动 Khoj：`khoj`
5. 回到 Obsidian，再次点击 `Force Sync`

### 6.3 搜索结果“驴唇不对马嘴”

**可能原因与解决**：

| 原因 | 解决方案 |
|------|----------|
| 提问太“关键词化” | 改用完整句子提问 |
| 索引未完成 | 等待 `Force Sync` 跑完再看结果 |
| 误用了“当前文件”模式 | 检查是否选择了 `use current file`，切换为全局搜索 |
| 噪音文件夹被索引 | 在 `Exclude Folders` 中排除 Templates、Excalidraw 等 |
| 索引损坏 | 按 6.2 的方法重置索引 |

### 6.4 插件更新

在 Obsidian 设置 → 社区插件中，点击 **检查更新**，如有 Khoj 更新则点击更新按钮。


## 七、日常使用建议

### 7.1 推荐工作流

1. **日常检索**：用 **Search** 模式，输入完整描述性句子
2. **发现关联**：打开一篇笔记，用 **Similar** 模式发现相关内容
3. **深度问答**：配置好 AI 模型后，用 **Chat** 模式进行对话式探索
4. **定期同步**：保持 `Auto Sync` 开启，确保新笔记被索引

### 7.2 保持索引“干净”

- 定期检查 `Exclude Folders` 列表
- 不要把大量重复性内容（如模板、日记模板）放在主索引范围内
- 如果觉得搜索结果变差了，可以尝试 `Force Sync` 重建索引

### 7.3 启动服务的快捷方式

如果你已经把环境变量写入了 `~/.zshrc`，每次使用只需：

```bash
khoj
```

然后保持终端窗口打开，在 Obsidian 中正常使用即可。
