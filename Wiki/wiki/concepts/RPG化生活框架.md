# RPG化生活框架

> **定义**：将生活游戏化（RPG化）以替代意志力依赖，构建可持续的行为系统。

## 核心表格

| 游戏要素 | 现实对应 | 定义 |
| :--- | :--- | :--- |
| **通关条件** | **愿景** | 你渴望的终极状态。 |
| **Game Over** | **反向愿景** | 掉下去就是万劫不复的底线。 |
| **主线任务** | **1年目标** | 目前唯一的最高优先级。 |
| **BOSS 战** | **1月项目** | 具体的攻坚战（如：练出腹肌、上线产品）。 |
| **刷经验** | **每日杠杆** | 推动项目进度的关键动作。 |
| **游戏规则** | **绝对约束** | 为了赢绝不触碰的红线（如：睡前不看手机）。 |

## 设计原则

1.  **明确边界**：Game Over 定义了绝对不能触碰的底线
2.  **单一主线**：同一时间只有一个1年目标作为最高优先级
3.  **可量化**：BOSS战和刷经验需要具体、可追踪
4.  **身份绑定**：游戏规则与"我是哪种人"的身份声明一致
